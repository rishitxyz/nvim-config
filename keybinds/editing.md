# Editing

| Keys | What it does |
|---|---|
| `Space ca` | Code actions: quick fixes, adding imports and so on |
| `Space cr` | Rename a symbol everywhere |
| `Space cf` | Format the file or selection |
| `Space uf` | Turn format on save on or off for this buffer only. It starts off. |
| `Space uh` | Show or hide inline type hints |
| `gcc` / `gc` + motion | Comment out a line / the lines a motion covers. Built into Neovim. |
| Completion menu | `Enter` accepts, `Ctrl+n` / `Ctrl+p` move up and down, `Ctrl+e` closes it |
| `Esc` | Clear search highlighting |
| `⌘+` / `⌘=` (Neovide) | Increase font size by one point |
| `⌘−` (Neovide) | Decrease font size by one point |
| `⌘0` (Neovide) | Reset font size to 20 points |

Neovide uses Google Sans Code at 20 points, matching Ghostty's font family and size. Font shortcuts work in normal, visual, operator-pending, insert, command-line and terminal modes. Zoom changes last for the current Neovide session.
