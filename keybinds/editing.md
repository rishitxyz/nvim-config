# Editing

| Keys | What it does |
|---|---|
| `Space ca` | Code actions: quick fixes, adding imports and so on |
| `Space cr` | Rename a symbol everywhere |
| `Space cf` | Format the file or selection |
| `Space uf` | Turn format on save on or off. It starts off. |
| `Space uh` | Show or hide inline type hints |
| `gcc` / `gc` + motion | Comment out a line / the lines a motion covers. Built into Neovim. |
| Completion menu | `Enter` accepts, `Ctrl+n` / `Ctrl+p` move up and down, `Ctrl+e` closes it |
| `Esc` | Clear search highlighting |
