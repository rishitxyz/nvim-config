# Repos, tabs and files

Leader is Space. Each tab has its own working directory, so file search, git and LSP stay inside the repo open in that tab.

| Keys | What it does |
|---|---|
| `Space fp` | Pick a repo from `~/dev/*` or an agent worktree in `~/.t3/worktrees` and open it in its own tab |
| `Space fw` | Pick one of the current repo's git worktrees and open it in its own tab |
| `Space Space` | Find a file by name |
| `Space /` | Search text across the repo |
| `Space ,` | Switch between open buffers |
| `Space fr` | Recently opened files in this repo |
| `-` | Open the folder of the current file in oil. Edit the listing like text and save to rename, move or delete files. `q` closes it. |
| `gt` / `gT` or `]t` / `[t` | Next / previous tab |
| `Space tn` / `Space tc` | New tab / close tab |
| `Ctrl+h/j/k/l` | Move to the split on the left / below / above / right |
| `Space w` | Save |
